# 03 · 常用指令集

> 所有命令都在 `tools/` 目录下执行（`cd` 进去之后跑）。
> 依赖：Python 3.7+。主功能纯标准库零依赖；`--crop` / `--chroma` / 平均合成 需要
> `pip install pillow numpy`。

---

## 1. 探测与测速

```cmd
:: ★ 自检：定位设备 + 连续读 8 次看帧是否变化（先跑这个确认设备在位）
python live_view.py --probe

:: 手动指定设备路径（盘符认不出时）
python live_view.py -d H:\elen1 --probe

:: 只测帧率（10 秒采样）
python live_view.py --fps
```

期望：`--probe` 输出 8 个不同的 md5，帧率 18~20 次/秒。
⚠️ 跑探测前**先停掉正在 `--serve` 的进程**（同一时刻只能有一个读取者，坑 7）。

---

## 2. 拉起网页实时画面

```cmd
:: ★ 最常用：起本机服务，浏览器打开 http://127.0.0.1:8081
python live_view.py --serve

:: 换端口
python live_view.py --serve -p 9000

:: 同时裁掉底部 OSD 文字带（需 Pillow）
python live_view.py --serve --crop 80

:: 允许局域网访问（无鉴权，只在可信网络开）
python live_view.py --serve --host 0.0.0.0
```

### 网页页面自带的功能（浏览器里点按钮）

起完 `--serve` 后，页面底部有两组按钮：

| 按钮 | 行为 | 输出 |
|---|---|---|
| ● 录制（输入秒数，默认 30，可勾选「色彩还原」） | 抓 N 秒封成 MP4；勾选则逐帧离线过色彩还原 | `captured/video/dashcam_时间戳.mp4` |
| 📷 拍照（输入曝光秒数，默认 2，可勾选「色彩还原」） | 两步走：先采集全部帧 → 再逐像素平均合成；勾选则合成后离线过色彩还原 | `captured/photo/photo_时间戳.jpg` |

- 右上角绿色时钟 = 主机本地时间（实时走）
- 黄色提示区会分阶段显示：**"正在采集（曝光 Ns）…" → "正在合成（M 帧平均）…"**
- 拍照/录制进行时，网页画面流自动暂停（帧门控），结束后自动恢复
- 输出目录都是相对工具目录的 `captured/`，即 `tools/captured/photo/` 和 `tools/captured/video/`

### HTTP 端点（给别的程序用）

| 端点 | 用途 |
|---|---|
| `/` | 带状态栏 + 按钮的观看页 |
| `/stream` | 标准 MJPEG 流（`multipart/x-mixed-replace`），OpenCV/ffmpeg 可拉 |
| `/snapshot` | 单张 JPEG 快照 |
| `/stat` | JSON 状态：`{"seq","fps","reads","errors","frame_kb"}` |
| `/record?n=秒数` | 触发一次录制（JSON 返回文件路径） |
| `/photo/capture?n=秒数` | 拍照第一步：采集（返回帧数） |
| `/photo/process` | 拍照第二步：平均合成 + 保存（返回文件路径） |
| `/media?kind=all\|photo\|video` | 列出 captured/ 下已有文件（JSON） |
| `/media/photo/xxx.jpg`、`/media/video/xxx.mp4` | 取文件（图片/视频，网页预览区在用） |

说明：带 `chroma=1` 的端点（`/record?n=30&chroma=1`、`/photo/process?chroma=1`）
对应网页上的「色彩还原」勾选框，不依赖启动参数。

## 3. 命令行拍照 / 录制

```cmd
:: 拍照：2 秒曝光，逐像素平均合成，存 captured/photo/
python live_view.py --photo

:: 自定义曝光时长（1~60 秒，越大平均帧数越多、噪声越低）
python live_view.py --photo --exposure 5

:: 录 30 秒视频（默认），存 captured/video/
python live_view.py --record

:: 录 10 秒
python live_view.py --record -t 10
```

### ★ 加色彩还原（离线，方案 A）

```cmd
:: 拍照 + 自动色彩还原（锁 L* + M2 色度矩阵 + 通道截断 + Bayer 抖动）
python live_view.py --photo --exposure 2 --chroma

:: 录 30 秒 + 逐帧色彩还原（30s ≈ 600 帧 × 1.6s ≈ 16 分钟，慢慢跑）
python live_view.py --record -t 30 --chroma
```

- 公式与参数来自 `色彩还原/色彩还原公式.md`（标定数据、复现代码都在那）
- 原图会自动留 `.pre` 备份（如 `photo_xxx.jpg.pre`），随时可找回
- 不带 `--chroma` 时零额外开销
- 需要 `pip install pillow numpy`

## 4. 离线色彩还原（独立模块）

```cmd
:: 对任意一张 JPEG 跑色彩还原（输出 <原文件名>_chroma.jpg，1.6 秒/张）
python chroma_restore.py ..\..\拍摄图像.jpg

:: 直接对 captured/photo/ 里已拍的照片补跑（比如当时没加 --chroma）
python chroma_restore.py captured\photo\photo_xxx.jpg
```

模块也可 import 进自己的脚本：

```python
import chroma_restore
out_bytes = chroma_restore.apply(jpeg_bytes)        # bytes → bytes（q95）
out_img   = chroma_restore.apply_pil(img)            # PIL → PIL
```

## 5. 存帧 / 测速（实验用）

```cmd
:: 存 300 帧到 frames/
python live_view.py --save -n 300

:: 每秒一张存 60 张
python live_view.py --save -n 60 --interval 1.0

:: 存帧时一起裁 OSD
python live_view.py --save -n 60 --crop 80
```

## 6. 停止服务

`--serve` 进程：`Ctrl+C`（终端里），或：

```cmd
:: 杀掉 8081 端口的进程
Get-NetTCPConnection -LocalPort 8081 | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

## 7. 输出文件位置一览

| 功能 | 输出路径（相对 tools/） |
|---|---|
| 网页/命令拍照 | `captured/photo/photo_YYYYMMDD-HHMMSS.jpg` |
| 网页/命令录制 | `captured/video/dashcam_YYYYMMDD-HHMMSS.mp4` |
| 色彩还原备份 | 同名 `.jpg.pre`（原图） |
| 存帧实验 | `frames//live_%04d.jpg` |

MP4 是纯手写封装（ftyp+moov+mdat，mjpeg fourcc，零依赖），
Photos / QuickTime / 网页都能放；要求严格的场景可以用 ffmpeg 转 H.264：

```cmd
ffmpeg -i captured\video\dashcam_xxx.mp4 -c:v libx264 out_h264.mp4
```
